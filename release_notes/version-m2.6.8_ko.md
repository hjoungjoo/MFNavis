# MF PiFinder m2.6.8

구름으로 솔빙이 끊겨도 진행 중인 GOTO와 추적 목표를 유지하고, 목표에서 멀어지는 보정을 감지해 새 솔빙으로 다시 접근하도록 개선했습니다.

## 주요 변경

- GOTO 이동 후 새 솔빙이 늦어지면 대기하고, 솔빙이 복구되면 보정을 이어갑니다. 오래된 좌표나 IMU 추정 좌표로 도착을 확정하지 않습니다.
- 한 번의 오차 증가로 GOTO를 종료하지 않습니다. 보정 횟수 한도에 도달하면 10초 대기 후 새 솔빙으로 같은 목표에 재시도합니다. 추적 복구도 대기 후 계속됩니다.
- 근거리 물리축 조정이 수렴하지 않으면 같은 목표를 sync+GOTO로 다시 획득합니다. 펄스 보정 후 오차가 연속해서 커지는 경우에도 추가 펄스를 중단하고 재획득합니다.
- 해당 목표에서 수렴하지 않았던 미세 보정으로 다시 돌아가지 않도록 했습니다. 사용자 정지, 주차, 통신·동기화 오류와 기존 추적 고도 제한은 유지합니다.
- 이전 릴리즈 이후의 GOTO 좌표 표시 응답 개선, SEP 비상 복구 경로 정리, 솔빙 검색 및 프레임 버퍼 최적화를 포함합니다.
- 고정 MFDS 바이너리를 0.3.2로 갱신했습니다. 개발용 Graft 코드 탐색 안내도 포함합니다.

## 관측 검증과 한계

2026-09-18 실측에서 GOTO 오차가 340.87 → 19.34 → 8.47 → 0.99분각으로 감소해 정렬을 완료했습니다. 이후 추적 오차가 한때 약 6.5분각까지 증가했다가 줄었고, 마지막 36초 관찰에서는 2.07~2.39분각으로 설정된 3분각 이내를 유지했습니다.

새 발산 복구 분기의 동작은 회귀 테스트로 검증했습니다. 실측에서는 해당 분기가 작동할 정도의 지속적인 발산이 재현되지 않았습니다. 마운트의 물리적인 축 응답 불일치 원인은 확정하지 않았으며, 장시간 추적 정밀도는 추가 관측이 필요합니다.

상세 기록: [GOTO 드리프트 복구 검증](../docs/mf_report/mf_goto_drift_recovery_20260918_ko.md).
