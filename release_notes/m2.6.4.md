# MF PiFinder m2.6.4

최종 MF 검출기와 전처리·통합 코드·집계 자료의 공개 저장소를
[MFDS](https://github.com/hjoungjoo/MFDS)로 전환한 정식 소스 릴리즈입니다.

- PiFinder는 공개 MFDS `2be2336635384e350fb50f9fcc91f501c00a4dde`를 고정해 사용하며 개인 SSH 키 없이 설치·CI 빌드가 가능합니다.
- native 검출·전처리 알고리즘과 실행 ABI는 m2.6.3과 동일합니다. 기존 `mf_detect_star` 내부 이름과 설치 경로는 유지합니다.
- 기존 FSL 5년 MIT 전환 조건, GPL 통합 코드와 MIT 출처 고지를 유지합니다. 자세한 범위는 [MFDS 라이선스](https://github.com/hjoungjoo/MFDS/blob/2be2336635384e350fb50f9fcc91f501c00a4dde/LICENSING.md)를 참고하세요.
- 기존 비공개 mf_detect_star 저장소는 새 저장소 검증 후 삭제합니다. 이전 태그는 변경하지 않으며, 신규 설치에는 m2.6.4를 사용하세요.

## 설치

```bash
git clone --recurse-submodules --branch m2.6.4 https://github.com/hjoungjoo/MF_PiFinder.git PiFinder
cd PiFinder
bash scripts/ensure_tetra3_link.sh .
bash scripts/setup_mf_detect_star.sh
```

m2.6.3에서의 기존 장비 전환은 [이관 안내](../docs/MFDS_MIGRATION_ko.md)를 참고하세요. 소스 ZIP/tar.gz에는 submodule이 포함되지 않으며 별도 SD 이미지는 제공하지 않습니다.
사용자 장비의 90초각 GoTo 완료 설정은 보존하며, 다른 장비의 기본 설정을 강제로 바꾸지 않습니다.

검증 결과와 CI 링크는 게시된 릴리즈 본문에 기록합니다.
