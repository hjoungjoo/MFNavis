# MFNavis m2.6.14 — Web language selection and observation logging

## English

- Select English or Korean beside the theme control. English is the default;
  the browser remembers the selection. Korean uses astronomical terminology
  and a bundled offline font. License notices and the source/installation guide
  open in the selected language.
- Restore the Network Setup selection labels and reduce horizontal margins in
  the header, footer and pages other than LiveCam.
- Fix document links that stopped working after returning with the browser's
  Back button. Restore navigation state when a page returns from the browser cache.
- Add **Add to Observations** to catalog object, planet and Moon details.
  The button saves the selected target with the observation time and location,
  then opens its observing session. It does not move the telescope.
- Move repetitive solver diagnostics and Auto(Star) framewise exposure messages
  from INFO to DEBUG while retaining normal operational INFO messages.
- Include all changes since m2.6.13: standardized MFNavis installation/update
  paths, service-user web authentication, measured IMX462 Color defaults for
  new installs, installation/INDI/cache fixes and the transparent product logo.

MFDS remains pinned to v0.4.1. This is a software-source release with installation
materials, not an OS image. Refresh open browser pages after updating.

## 한국어

- 테마 옆에서 영문·한글을 선택할 수 있습니다. 기본값은 영문이며 브라우저에
  선택을 저장합니다. 한글은 천문 용어와 내장 글꼴을 사용합니다. 오픈소스 고지와
  소스 제공·설치 안내도 선택한 언어로 열립니다.
- Network Setup 선택 항목의 제목을 복구하고 LiveCam을 제외한 페이지와
  상단·하단 영역의 좌우 여백을 줄였습니다.
- 문서를 열고 브라우저 뒤로 가기로 돌아온 뒤 링크가 다시 열리지 않던 문제를
  수정했습니다.
- 카탈로그 천체·행성·달 상세 페이지에 **관측 기록에 추가** 버튼을 추가했습니다.
  선택한 천체와 관측 시각·위치를 기록하고 해당 관측 세션으로 이동합니다.
  망원경 이동 명령은 보내지 않습니다.
- 반복되는 솔버 진단과 Auto(Star) 프레임별 노출 메시지를 DEBUG로 옮겼습니다.
  운영에 필요한 INFO 로그는 유지합니다.
- m2.6.13 이후의 MFNavis 설치·업데이트 경로 통일, 서비스 계정 웹 로그인,
  신규 설치 IMX462 Color 실측 기본값, 설치·INDI·캐시 수정과 투명 로고도 포함합니다.

MFDS v0.4.1 고정 버전을 유지합니다. OS 이미지가 아닌 소프트웨어 소스와 설치
