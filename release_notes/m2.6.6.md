- PiFinder 통합 안내의 표현도 MFDS 자체 정책으로 정리했습니다.
- 기존 5년 후 MIT 전환 조건, 저작권 고지, GPL 통합 코드와 과거 MIT 권한·공개일은 유지합니다.
- m2.6.5 대비 검출·솔빙·병렬 전처리 동작과 사용자 설정은 동일합니다. 이전 릴리즈의 성능 검증은 그대로 참고하며 이번 표기 변경의 새로운 성능 개선으로 제시하지 않습니다.

```bash
git clone --recurse-submodules --branch m2.6.6 https://github.com/hjoungjoo/MF_PiFinder.git PiFinder
cd PiFinder
bash scripts/ensure_tetra3_link.sh .
bash scripts/setup_mf_detect_star.sh
python/mf_detect_star/build/mf_detect_star_server --version
```

GitHub 자동 소스 아카이브에는 submodule이 포함되지 않으므로 재귀 clone을 사용하세요. 별도 SD 이미지는 제공하지 않습니다. 기존 태그·부팅 설정·이 장비의 90초각 GoTo 완료 기준은 유지합니다.
