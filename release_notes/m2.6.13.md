# MFNavis m2.6.13 — 작은 별 수정 및 LiveCam 상태 표시 개선

MFDS v0.4.1을 고정 패키지로 사용합니다. 4×4 축소 후 작은 별이 초기
크기·모양 검사에서 제외되던 문제를 수정한 버전입니다. 기존 전체 4×4 탐색과
후보 주변 2×2 정밀화, 정밀 단계의 잡음 제거 조건은 유지합니다.

RAW·전처리 화면은 품질 필터를 통과한 후보를 최대 128개까지 표시합니다.
솔버 입력은 기본 48개로 유지하며 추가 전체 영상 탐색은 없습니다.
초록색 표시는 카탈로그 매칭된 별, 주황색 표시는 검출 후보입니다.

LiveCam에서 영상 소스와 프리뷰 활성 여부에 관계없이 전처리 상태를 표시하고,
마지막 솔빙 결과·마지막 성공 이후 시간·검출/매칭 별 수를 제공합니다.
IMU가 유지한 좌표와 마지막 카메라 솔빙 결과를 구분해 실패 상태를 표시합니다.

일반 MFDS와 별도로 상용 프로필의 정식 패키지도
`deployment/mfds-commercial.lock.json`에 고정했습니다. 일반 설치는 기존처럼
일반 패키지를 사용하며 상용 프로필로 자동 전환하지 않습니다.

기존 RAW 40장에서는 이전 native 후보 1,936개를 모두 유지하며 12개를
추가 검출했고, 검출 시간 중앙값은 44.12 → 42.56 ms였습니다. 추가 후보는
카탈로그로 확인한 별 수가 아니며 현재 8 mm 촬영 원본 RAW 검증은 남아 있습니다.

업데이트 시 새 MFDS 패키지의 아카이브·manifest·내부 파일 해시와 버전을
검증합니다. 실행 중인 서비스는 다음 시작부터 새 코드를 사용합니다.
이 릴리즈는 소프트웨어 소스와 설치 자료이며 OS 이미지를 포함하지 않습니다.

검증: 단위·스모크 2,771 통과 / 4 건너뜀, UI 모듈 296 통과 / 2 건너뜀,
Ruff lint·format, MyPy 210개 파일 및 패키지 무결성 검사 통과.
