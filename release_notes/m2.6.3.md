# MF PiFinder m2.6.3

Cedar Detect를 MF 검출기로 교체하고, 광해 환경의 RAW·전처리 솔빙과 GoTo 초기 좌표 대기를 개선한 정식 소스 릴리즈입니다.

## 주요 변경

- MF4p 피라미드 검출을 RAW·전처리 영상에 사용합니다. 네이티브 검출기는 별도 프로세스와 private memfd로 통신하며, SEP는 MF 검출 불가·후보 부족 시 보조로 사용합니다.
- 전처리는 병렬로 수행하고 auto 스케줄을 기본으로 사용합니다. RAW 실패 또는 정렬·보정 상황에서는 필요한 전처리 결과를 기다리는 복구 경로를 유지합니다.
- Tetra3 검색과 전처리 비용을 줄이고, 오래된 보정값·좌표 사용을 제한했습니다. 관측 자료에 목표 및 관측 좌표를 함께 기록하도록 개선했습니다.
- 첫 GoTo가 광학 좌표를 기다리다가 진행되지 않는 문제를 수정했습니다. 최종 제어 동작과 실측 범위는 [GoTo 검증 기록](../docs/GOTO_INITIAL_ANCHOR_FIX_ko.md)을 참고하세요.
- Cedar 서버·클라이언트·서비스·전용 비교 도구와 RPC 설치 의존성을 제거했습니다. 설치·갱신 시 Cedar 재유입 검사와 MF 커밋 고정을 사용합니다.

## 검증 및 설정

로컬 단위·스모크 2,436개 통과(2 skip), lint 및 427파일 포맷 통과, 206소스 타입 검사 통과, MF 네이티브 회귀 6/6과 라이선스·레이아웃 검사를 통과했습니다. 게시된 릴리즈 본문에 GitHub Actions 링크를 기록합니다.

운영 장비에서 MF worker와 새 솔빙을 확인했습니다. 재부팅 및 Cedar 제거 검증 당시 마운트는 꺼져 있었으므로 해당 점검을 GoTo 실물 이동 검증으로 해석하지 않습니다. 이전 광해·달·도심 조명·토성 실측의 조건과 한계는 [통합 문서](../docs/DETECTOR_INTEGRATION_ko.md)에 연결되어 있습니다.

사용자 장비의 GoTo 완료 기준 90초각(1.5분각)은 로컬 설정입니다. 이 릴리즈가 다른 장비의 설정을 해당 값으로 강제 변경하지 않습니다.

## 소스와 설치

```bash
git clone --recurse-submodules --branch m2.6.3 https://github.com/hjoungjoo/MF_PiFinder.git PiFinder
cd PiFinder
bash scripts/ensure_tetra3_link.sh .
bash scripts/setup_mf_detect_star.sh
```

`python/mf_detect_star`는 MF 저장소 커밋 `2f556b4`에 고정됩니다. MF 저장소는 현재 비공개이며 위 명령과 설치·빌드에는 해당 저장소 읽기 권한이 필요합니다. GitHub 자동 생성 ZIP/tar.gz에는 서브모듈 내용이 포함되지 않습니다. 별도 SD 카드 이미지는 제공하지 않습니다.

이전 Cedar 기반 m2.6.0에서 올라오는 경우 검출기·서브모듈·의존성 구성이 달라 단계적인 설치 전환이 필요합니다. 기존 사용자 설정·관측 자료를 보존하고, [설치 안내](../docs/mf_dev/mf_bookworm_install_ko.md)와 [전환 기록](../docs/MAIN_FINALIZATION_ko.md), [Cedar 제거 범위](../docs/CEDAR_REMOVAL_ko.md)를 확인하세요. 소스 업데이트와 OS·패키지 설치는 별도 절차입니다.

PiFinder/Tetra3의 라이선스·출처 고지와 MF의 별도 라이선스 조건을 유지합니다. 이 릴리즈는 라이선스 변경이나 Git 과거 기록 삭제가 아닙니다.
