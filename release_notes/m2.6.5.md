# MF PiFinder m2.6.5

MFDS [v0.2.0](https://github.com/hjoungjoo/MFDS/releases/tag/v0.2.0), 커밋 `15da1f813893e54d302e8a8bd23f2c6d2c50720c`를 고정해 사용하는 정식 소스 릴리즈입니다. 밝은 별의 포화 중심 제외로 인한 RAW 실패와 동기·비동기 전환 반복을 수정했습니다.

- MFDS 버전은 PiFinder와 독립적으로 관리합니다. native CLI/서버의 `--version`, C API로 확인할 수 있고 관측 캡처 manifest의 `detector_runtime.mf_source_version`·버전 파일 해시·기존 커밋/실행 파일 해시로 출처를 기록합니다. 소스 버전 필드는 디스크 소스의 버전이며 이미 실행 중인 바이너리 버전의 증명은 아닙니다.
- RAW와 512 입력을 같은 프레임으로 전달하고 검출 중 RAW 재읽기를 제거했습니다.
- 정상 솔빙의 연속성 확인 대기를 검출 실패 backoff에 넣지 않습니다. 병렬 전처리·안정된 좌표 보정과 RAW 실패/정렬/보정 시 동기 복구는 유지합니다.
- m2.6.4 태그 이후 main에 적용된 Cedar 운영·설치·갱신 경로 정리를 포함합니다. NixOS와 SEP 보조, 라이선스 고지는 유지합니다.
- 검증된 알고리즘의 고정 장비 실측은 323/323 성공, 3분 telemetry 처리 지연 중앙값 123.71ms·p95 176.97ms였습니다. RMSE 중앙값은 21.85초각이며 절대 지향 오차나 이동 중 GoTo 성능을 뜻하지 않습니다. [상세 측정](https://github.com/hjoungjoo/MF_PiFinder/blob/m2.6.5/docs/mf_report/mf_compact_saturation_frame_pair_fix_20260916_ko.md).

## 설치

```bash
git clone --recurse-submodules --branch m2.6.5 https://github.com/hjoungjoo/MF_PiFinder.git PiFinder
cd PiFinder
bash scripts/ensure_tetra3_link.sh .
bash scripts/setup_mf_detect_star.sh
python/mf_detect_star/build/mf_detect_star_server --version
```

GitHub 자동 소스 ZIP/tar.gz에는 submodule 내용이 포함되지 않으므로 재귀 clone을 사용하세요. 별도 SD 이미지는 제공하지 않습니다. 기존 사용자 설정과 이 장비의 GoTo 완료 기준 90초각은 보존합니다. 과거 태그는 이동하지 않습니다.

MFDS의 native FSL 5년 MIT 전환 조건, GPL 통합 코드와 과거 MIT 고지는 유지합니다. [라이선스 범위](https://github.com/hjoungjoo/MFDS/blob/v0.2.0/LICENSING.md)를 참고하세요. 검사 결과와 고정 커밋은 게시 릴리즈 본문 및 작업 보고서에 기록합니다.
