# MFNavis m2.6.15 검증 기록

검증일: 2026-10-07. Raspberry Pi 5 / Raspberry Pi OS Trixie 64-bit / Python 3.13.5.

## 범위

m2.6.14 이후 Trixie 설치·INDI 제어·영상 추적·정렬·카메라 변경과 SkySafari
초기 IMU 좌표, LCD 중복 제목, `0` 키 추적 정지를 포함한다. MFDS는 v0.4.2,
소스 커밋 `fb38aa73154c8977e0903cb8c6f3d70f1810e57c`로 고정한다.

## 자동 검사

- 단위 테스트: **3,353 통과**. 스모크 테스트: **7 통과**.
- UI 모듈 검사: **296 통과, 2 건너뜀**.
- 릴리즈 준비 중 추가한 INDI 연결 해제 회귀 검사와 카메라·웹 번역 대상
  검사: 287 통과. 위 전체 단위 검사에도 포함한다.
- Ruff lint / format: 463개 파일 검사 통과.
- MyPy: 233개 소스 파일 검사 통과.
- Sphinx: 누락 참조와 경고를 실패로 처리한 전체 문서 빌드 통과.
- 한국어 웹 문자열의 PO / MO 완전성과 번역 적용 검사 통과.
- `smooth_tracking.js` 및 설치 스크립트 구문 검사 통과.
- Cedar 잔존 검사와 설치된 MFDS 패키지 manifest / 내부 파일 해시·버전 검증 통과.
- Git에 포함된 Trixie INDI 분할 아카이브의 합산 SHA256을 sidecar와 대조했다.

이전 CI 실패의 카메라 게인 및 INDI client 타입 오류, 새 트래킹 화면의 번역
6개 누락을 수정했다. 최초 로컬 단위·스모크 실행은 sandbox에서 GPIO 라이브러리
import가 제한되어 수집에 실패했으며, 격리된 개발 데이터·runtime 경로를 유지하고
실제 호스트 환경에서 전체 재실행하여 통과했다. 기존 의존성의 deprecation 경고는 남아 있다.

## 실기 확인 및 한계

- 서비스에서 초기 미솔빙 좌표가 `IMU_PRIMARY_UNSOLVED`로 유효하게 게시되고,
  GPS 미수신 시 마지막 OnStep 위치를 사용하여 SkySafari 프로토콜 RA / Dec 응답을
  제공하는 것을 확인했다. 물리·수동 이동과 솔빙 전후 전환은 자동 회귀 검사에 포함한다.
- 실제 OnStepX `TELESCOPE_TRACK_STATE`의 `TRACK_OFF=On`과 런타임의
  `tracking_enabled=false`, `mount_motion_active=false`, 목표 해제를 확인했다.
- 이번 준비 중 실제 하늘 GoTo·추적 정확도 측정이나 새 SD 전체 설치는 수행하지 않았다.
  자동 검사 결과가 실제 하늘 추적 성능을 보증하지는 않는다.
- Pi 4·CM5 Trixie와 IMX678 센서 광도·SQM 보정은 별도 실기 검증 대상이다.

이번 배포는 소프트웨어 소스 및 설치 자료다. 판매용 OS 이미지와 그 대응소스
묶음의 출하 검증은 이번 범위에 포함하지 않는다. 개인 관측 영상과 운영 설정은 공개하지 않는다.
