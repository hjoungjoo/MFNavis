# MFNavis m3.0.0 검증 기록

검증일: 2026-10-14. Raspberry Pi / Trixie 64-bit / Python 3.13.5.

## 변경 범위

- Finder 메뉴와 카메라·차트 모드, 표시된 마크 중심 좌표의 GOTO.
- Finder의 기본 푸시 화면 진입 단축키 제거와 수동 이동 유지.
- Chart와 Finder의 IMU 좌표 표시 및 Finder의 IMU 좌표 GOTO.
- `version.txt`를 `m3.0.0`으로 갱신하고 한·영 릴리즈·설치 자료 준비.
- `main`에 반영된 GOTO·추적·OnStep 복구 개선을 포함하며, MFDS는 고정된
  v0.4.4 패키지를 사용한다.

## 로컬 검증 결과

`scripts/activate_dev_trixie.sh`로 개발 환경과 분리된 테스트 데이터를 선택했다.

| 검사 | 결과 |
| --- | --- |
| Nox lint | 통과 |
| Nox format | 481개 파일 통과 |
| Nox type_hints | 240개 소스 파일 통과 |
| Nox smoke_tests | 7개 통과 |
| Nox unit_tests | 3,938개 통과 |
| Nox ui_tests | 298개 통과, 2개 건너뜀 |
| Nox docs | 경고를 오류로 처리하는 Sphinx 빌드 통과 |
| Cedar 운영 잔여 검사 | 통과 |
| 고정 MFDS 설치 패키지 검증 | v0.4.4 linux-aarch64 통과 |

UI에서 건너뛴 두 항목은 일반 키 순회로 검증할 수 없는 기존 UIAlign의
실시간 솔빙·정렬 순서에 해당한다. 검사 생략 규칙을 추가하지 않았다.

Finder 테스트는 128·176·320 화면, 두 모드 순환, 확대·축소, 표시 좌표 고정,
5번 키와 ALIGN의 GOTO 큐 전달, 잘못된 좌표 차단, IMU 손실·복구,
오른쪽 키의 짧은·긴 누름과 수동 이동을 확인한다. 독립된 Chart의 천체 상세
화면 이동도 회귀 검사한다.

실행 명령:

```bash
source scripts/activate_dev_trixie.sh
python -m nox --no-venv -s lint format type_hints smoke_tests unit_tests ui_tests
python -m nox --no-venv -s docs
python ../scripts/check_cedar_free.py --repo ..
bash ../scripts/setup_mfds.sh
```

## 게시 전 확인과 범위

정식 게시 전 동일 소스 커밋의 GitHub Nox 검사를 확인한다. Python 3.11의
호환성 검사와 Trixie Python 3.13의 코드·문서·설치 검증 실행 링크는
릴리즈 본문 및 `release-manifest.json`에 기록한다. 설치 자료는 해당 소스
커밋에서 추출하며 첨부 파일의 SHA256을 제공한다.

이번 Finder 검증에서는 실제 마운트를 연결하지 않았다. 실제 이동, 하늘 관측
중 추적 정확도, 새 SD 카드 전체 설치와 판매용 OS 이미지 검증은 포함하지 않는다.
