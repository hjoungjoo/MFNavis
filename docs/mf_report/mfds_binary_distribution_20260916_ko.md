# MFDS 빌드 산출물 소비 전환

## 작업 전

PiFinder가 MFDS Git 소스를 서브모듈로 가져와 로컬 빌드하던 구조를, MFDS에서 수정·빌드·릴리즈하고 PiFinder는 고정된 산출물만 설치하는 구조로 전환한다. 알고리즘·카메라·마운트 설정은 변경하지 않는다.

## 구현

MFDS v0.3.0: GitHub Actions의 Bookworm 환경에서 Linux aarch64/x86_64 바이너리를 빌드·검사하고 패키지와 SHA-256을 공개 릴리즈에 게시했다. native 코드 변경 없이 버전·패키징만 추가했다. GPL Python 연동 코드와 도구·테스트·문서·라이선스는 배포 패키지에 포함하며 정본은 MFDS에서 관리한다.

PiFinder: 소스 gitlink/.gitmodules 제거, deployment/mfds.lock.json에 플랫폼별 아카이브·manifest 해시와 소스 커밋 고정. Python 표준 라이브러리 설치 도구가 아키텍처/ABI/경로/파일 해시/서버 버전을 확인한 후 패키지 링크를 교체한다. 기존 패키지는 롤백용으로 유지하며 다운로드·검증 실패는 현재 링크를 변경하지 않는다. 전체 소스 빌드 및 submodule 초기화를 설치·CI·업데이트 경로에서 제거했다.

## 검증

MFDS native·라이선스 CI와 두 아키텍처 패키지 CI 통과. PiFinder 바이너리 패키지 사용 상태에서 관련 72개 검사 및 전체 unit 2453개 통과(2 skipped), Ruff와 포맷 통과. 네트워크 실패, 잘못된 SHA-256, 캐시 변조, 잘못된 아키텍처, tar 경로 공격, 소스 폴더 덮어쓰기 거부, 업데이트 실패·중단 복구 검증 포함.

신규 다운로드 설치 및 실제 장비 최종 결과는 로컬 작업 기록과 커밋 후 CI 결과에 남긴다. 과거 성능 데이터를 이번 변경의 성능 향상으로 표현하지 않는다. 설치·버전 갱신 절차는 ../MFDS_BINARY_DISTRIBUTION_ko.md 참조.
