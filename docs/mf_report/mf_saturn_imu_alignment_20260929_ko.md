## 정렬 성공 후 Push 화살표 불일치

후속 확인에서 22:23:08과 22:23:55 정렬은 성공했고 정렬점은 최종
`(206.3622569548769, 250.4134633845032)`로 저장됐다. Push는 4× 영상이었다.
하지만 화살표와 원형 마크의 크기는 승인된 솔빙의 투영 정보 대신
기본 렌즈 시야각을 사용했다. 당시 imx462_color 기본 추정 시야각은
약 10.40도였다. 실제 정렬에 사용한 투영과 다른 스케일을 쓰면 목표가
정렬점에 일치해도 방향 화살표가 남을 수 있다.

LCD Push와 웹 LiveCam 마크를 승인된 솔빙의 FOV·프레임 크기·crop 변환에
맞췄다. 원형 마크는 측정된 crop 시야각으로 크기를 정하고, 방향은 정렬과
동일한 full-frame 픽셀 중심 규칙을 적용한다. 솔빙 투영이 없을 때만 기존
렌즈 시야각을 사용한다. 저장된 정렬점이나 모터 제어는 변경하지 않는다.

기본 렌즈와 측정 FOV가 다른 경우를 정사각형/세로/가로 프레임으로 재현해
정렬 직후 화살표가 사라지고, 실제 오른쪽 오차에는 오른쪽 화살표가 나오는
회귀 검사를 추가했다. 관련 **209 passed**, Ruff 검사 통과.
기존 IMU 추정 오차에 의한 실제 영상상의 어긋남은 이 표시 수정만으로
없애지 않으며 새 솔빙으로 구분해야 한다.
