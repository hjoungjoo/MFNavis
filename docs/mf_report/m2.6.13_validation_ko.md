# MFNavis m2.6.13 검증 — 2026-09-24

MFDS v0.4.1의 작은 별 후보 수정과 128개 표시용 후보를 연결했다.
기존 4×4 전체 탐색 → 2×2 ROI 정밀화, 솔버 기본 48개 입력을 유지한다.
LiveCam의 전처리·솔빙 상태 표시 변경도 함께 포함한다.

- MFDS 소스: `bdada844249c7bb9299e3f441324faffc6ff8231`
- 일반 패키지: `deployment/mfds.lock.json`

  상용 패키지는 별도 검증 checkout에서 설치 검사를 통과했다.

보완하고 전체 단위·스모크 검사를 다시 통과했다.

## 범위와 한계

MFDS의 저장 RAW 40장 비교에서는 기존 native 후보 1,936개를 유지하며
12개 후보가 추가되었고, 검출 중앙값은 44.12 → 42.56 ms였다. 추가 후보는
카탈로그 매칭으로 확인된 별 수가 아니다. 현재 8 mm 촬영의 원본 RAW가 없어
첨부 화면과 직접 비교하지 않았으며 물리 기기·브라우저 육안 검증도 하지 않았다.

일반 설치의 가속 설정은 유지한다. 상용 프로필은 별도 선택으로 CPU/NumPy
전처리를 사용한다. 이 소프트웨어 릴리즈가 상용 OS 이미지의 출하 검증이나
대응소스·설치 정보 준비를 대신하지 않는다. 실행 중 서비스의 재시작은
이 소스 릴리즈 절차에 포함하지 않았다.
