# 밝은 포화 별 보존과 프레임 전달 수정 — 2026-09-16

## 설계 및 검증 계획

맑은 하늘의 RAW 11장에서 기존 포화 제외는 0/11, 포화 제외를 해제한 오프라인 진단은 11/11 성공했다. 운영에서는 포화 제외 자체를 끄지 않고 다음을 적용한다.

- MFDS: 원본 센서 좌표에서 연결된 포화 영역을 판별한다. 96픽셀 이하·가로세로 16픽셀 이하의 작은 중심이고 주변 PSF 광량이 있을 때 보존한다. 넓은 영역·얇고 긴 영역·주변 광량 없는 밝은 점은 계속 마스킹한다.
- Python: MFDS가 이미 적용한 포화 마스크를 중복 적용하지 않는다. SEP 보조 검출은 동일한 작은 포화 중심·주변 PSF 판정을 적용한다.
- 프레임: 공유 상태에서 512 이미지와 해당 RAW를 한 묶음으로 게시한다. 검출기는 확보한 RAW를 그대로 사용하며 공유 슬롯을 다시 읽지 않는다. 불완전한 짝은 미솔빙으로 처리하지 않고 다음 입력을 기다린다.
- 병렬 전처리, RAW 실패·정렬·보정 중 동기 대기, NixOS, 90초각 GoTo 기준은 유지한다.
- 합성 포화 별·조명·불량화소·binning, 동일 RAW 재생, 과거 달/도심/구름 영상, 프레임 경합 회귀와 전체 검사를 수행한 뒤 운영에 적용한다.

## 결과

- MFDS `34a4806` (검출기 변경 `6ef8ab4`): native 7/7, 관련 Python 102개 통과. ASan/UBSan 및 호스트 누수 검사 7/7 통과.
- 동일 맑은 하늘 RAW 11장: 기존 0/11 → 수정 11/11. 검출+패턴 솔빙 중앙값 2,045.7 → 60.6ms, 수정 RAW RMSE 중앙값 20.99초각. 노출·공유 상태·게시 시간은 제외한 재생 측정이다.
- 달/도심 RAW 6장·전처리 6장은 기존·수정 모두 미솔빙, 구름 전처리 6장은 모두 5/6 성공. 전처리 12장의 검출 좌표는 완전히 동일했다.
- 단순 포화 해제와 달리 작은 포화 중심에도 주변 광량 조건이 적용된다. 작은 조명이 별과 동일한 PSF를 만들 수 있으므로 기존 형태·밀집도·패턴 품질 검증은 함께 유지한다.
