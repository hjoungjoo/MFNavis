# MFNavis m2.6.14 검증 기록

검증일: 2026-09-26. Raspberry Pi OS / Python 3.11 환경.

## 범위

m2.6.13 이후 누적된 설치·로그인·기본 광학 설정·로고 변경과 이번 웹 언어
선택, 문서 번역, 네트워크 제목·여백, 반복 진단 로그, 뒤로 가기 복원,
카탈로그 관측 기록 추가 변경을 포함한다. MFDS 고정 버전은 0.4.1이다.

## 자동 검증

- 단위·스모크 전체 실행: 2,825 통과, 4 건너뜀. 기존 솔빙 진단 화면 테스트
  1건이 한글 고정 화면을 전제로 하여 실패했다. 언어 초기화를 포함한 테스트
  구성과 영문 기본값 검증으로 수정한 뒤 해당 모듈과 언어 검사 70건이 통과했다.
  최종 단위·스모크 대상 2,826건은 전체 실행과 해당 재실행으로 검증했다.
- UI 모듈: 296 통과, 2 건너뜀.
- Ruff lint 및 format 검사 통과.
- 프로젝트 Nox와 동일한 `mypy PiFinder` 검사: 211개 소스 파일 통과.
- JavaScript 구문 검사 및 SPA 이동 회귀 검사 통과.
- Cedar 의존성 잔존 검사와 MFDS 설치 패키지 해시 검증 통과.

## 실제 브라우저 검증

- 영문·한글 선택, 유지, 모바일 배치와 한글 글꼴 표시 확인.
- 영문·한글 고지·설치 안내 링크 4개에서 브라우저 뒤로 가기 캐시 복원 후
  반복 클릭 확인. 운영 서비스에서도 동일 동작 확인.
- 임시 관측 DB에서 M31·달 상세 페이지 버튼을 영문·한글 각각 클릭하여
  저장과 관측 세션 이동 확인. 운영 관측 DB에 시험 기록을 추가하지 않았다.
- 서비스 재시작 후 활성 상태와 배포한 JavaScript 제공 확인.

OS 이미지나 새 SD 카드 전체 설치 검증은 이번 범위에 포함하지 않는다.
