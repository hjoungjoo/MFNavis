레이아웃 점검은 Firefox에서 실제 375px·1280px 뷰포트로 수행했습니다. 운영 데이터가 비어 있는 상세 화면은 격리 서버의 예제 데이터로 확인했습니다. 버튼 검사는 실제 장비 제어 버튼을 누르지 않고 브라우저 DOM의 비활성 상태와 계산된 스타일을 확인했으며, 클릭 차단은 별도 테스트 요소로 검증했습니다.

Tools의 로딩 멈춤은 실제 서비스에서 여러 차례 재방문하여 재현했습니다. 수정 후 연속 3회 재방문에서 상태 표시와 버튼 활성 여부가 정상임을 확인했습니다. 기존 이미지 다운로드 실패 기록을 성공으로 바꾸거나 자동 재시작하지 않았습니다.

## 배포와 범위

운영 서비스 재시작 후 정상 실행, CSS v14와 소스 일치, 새 Tools 초기화 코드 및 INDI HOLD의 disabled 속성을 확인했습니다. 사용자 설정·관측 자료와 이번 작업과 무관한 문서는 릴리즈에 포함하지 않습니다.

전체 저장소 CI는 릴리즈 커밋의 main/release 실행 결과를 확인한 뒤 게시하며, 실행 링크는 GitHub 릴리즈 본문과 첨부 release-manifest.json에 기록합니다. 첨부물은 커밋된 소스에서 추출하고 SHA256SUMS로 검증합니다.

이번 검증은 웹 UI와 관련 회귀 테스트를 대상으로 합니다. 새 SD 설치, OS 이미지 제작, 실제 다운로드 재개 및 망원경 구동은 검증 범위에 포함하지 않습니다.
