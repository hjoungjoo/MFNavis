`mfnavis_setup.sh`, 업데이트 경로, INDI 설치·패키징, GPS/Chrony, Wi-Fi 복구,
테스트 런타임 스크립트를 점검했다. 저장소의 셸 스크립트 전체에 `bash -n`을,
`scripts/`의 Python 파일에 `compileall`을 실행했다. 관련 테스트는 290개 통과,
4개 건너뜀; 설치·경로 테스트 추가 실행은 34개 통과했다. 변경된 Python 파일의
Ruff 검사와 `git diff --check`도 통과했다.
