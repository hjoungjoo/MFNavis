# 3경로 솔빙 실측 벤치 — cedar 크롭 / cedar 풀프레임 σ8 / cedar+SEP 하이브리드 (2026-08-01)

> 측정 기록. 배경·아키텍처는 [통합 구현 문서](../history/development/solver.md#mf_sep_fullframe_impl_ko)와

## 1. 측정 조건

- **일시/장소**: 2026-08-01 21:36–21:52 KST, 서울. 남쪽 하늘
  (RA≈230°, Dec≈−29°, Lup 방향), 고정 경통(무추적, RA 드리프트
  15.2″/s = 항성시 정합).
- **카메라**: imx462, **수동 노출 200 ms / 게인 30 고정** (자동 노출 off).
- **하늘 밝기**: raw 배경 p50 **3,558/4095 = 풀스케일의 87%** — 이 포크가
  겪은 밤 중 상당히 밝은 축(광해+박무). 세션 중 하늘이 눈에 띄게 호전
  (SEP 매치 med 9 → 16, 라이브 솔브율 41% → 100%).

## 2. 방법

**오프라인 3경로 (동일 프레임 50장)** — 스테이지 덤프를 12초 간격으로
50장 캡처(10분). 각 프레임에 대해:

| 경로 | 입력 | 검출 | 솔브 |
| --- | --- | --- | --- |
| **A. cedar 크롭 (현행 1차 경로)** | `06_solver_input.png` (512², 프로덕션 비트동일) | cedar σ8 / max_size 10 / binned / hot=on (프로덕션 파라미터 동일) | tetra3 (512², FOV 12°) |
| **B. cedar 풀프레임** | `00_raw_full.png` (1920×1080 12-bit) → 프로덕션 스트레치(바이어스 238 차감 후 8-bit) | cedar **σ8 / hot=on / binned=on** (요청 구성) | 센트로이드 90° 회전 + FOV 스케일 매핑 후 tetra3 |
| **C. 하이브리드 (현행 프로덕션)** | A 실패 시 12-bit 원본 | `sep_detect` σ4.0 + 웜픽셀맵 + 형태·클러스터 게이트 (프로덕션 모듈 그대로) | `solver_frame_map` 경유 tetra3 (프로덕션 동일) |

cedar는 실행 중인 cedar-detect-server(50551)에 **gRPC 인라인**으로 접속
(공유메모리 세그먼트 충돌 회피). 스크립트: 세션 스크래치패드
`bench3.py` / `aggregate_bench.py`.

**동일 노출 검증**: 하늘이 계속 변하므로 경로 간 비교는 반드시 같은
촬영본이어야 한다. 스테이지 덤프는 설계상 단일 노출의 단계별 저장이며,
추가로 50장 전수에 대해 `00_raw_full`(B·C 입력)에서 프로덕션 체인
(크롭→바이어스 차감→8-bit 스트레치)을 재계산한 통계가 같은 덤프의
8-bit 단계·`06_solver_input`(A 입력) 통계와 min/max/mean/p50까지
**비트 수준 일치(50/50)**함을 확인했다 — 세 경로는 프레임마다 같은 한
번의 노출을 본다. C의 cedar 1차는 A의 결과를 그대로 재사용한다.

**라이브 하이브리드 (프로덕션 그대로)** — `/api/solution`을 0.15 s 폴링,
15분간 **1,632 시도** 전수 기록. 오프라인 캡처와 같은 시간대.

## 3. 결과

### 3.1 솔브율·검출 (오프라인 50장 + 라이브 1,632시도)

| 지표 | A cedar 크롭 | B cedar 풀프레임 σ8 | C 하이브리드 |
| --- | --- | --- | --- |
| **솔브율 (오프라인 50장)** | **0% (0/50)** | **18% (9/50)** | **88% (44/50)** |
| 솔브율 (라이브 15분) | 0/1,632 (cedar 직접 0) | — | **89.5%** (후반 10분 ≈100%) |
| 검출 수 med | 1 (p90 1) | 5 (p90 9) — **크롭 창 안은 1개뿐** | SEP 17 (p90 23) |
| 매치 med (솔브 시) | — | 8 | 10 (라이브 med 13, 최대 22) |
| 순도 (매치/검출) | — | **89%** | 60% |
| RMSE med | — | 90″ | 81″ (라이브 87″) |

- 이 하늘에서 **cedar 크롭 경로는 완전 불능**(프레임당 0–1개 검출).
  라이브 15분 내내 cedar 직접 솔브 0 — 솔브 전량을 SEP이 담당.
- **cedar 풀프레임(요청 구성 σ8+hot+binned)은 18%**: med 5개를 찾지만
  크롭 창 안은 1개 — 즉 이득의 대부분이 시야 2.16배 확장분에서 나오는
  실별이다. 순도(89%)와 솔브 정확도는 최고지만 이 밝기에선 감도가 부족.
  §6.7(어두운 하늘)의 "512 대비 매치 3배" 잠재력은 밝은 하늘에선 못 살림.
- **하이브리드가 압도**: 같은 프레임에서 88%, 라이브 89.5%
  (하늘 호전 뒤 10분 연속 ~100%).

### 3.3 정확도 (드리프트 제거 산포, 고정 경통)

| 지표 | B cedar 풀프레임 | C 하이브리드 |
| --- | --- | --- |
| 1σ RA / Dec | 27″ / 36″ (n=9, 오프라인) | **57″ / 49″** (라이브 1,461솔브, 2분 부창 med; 창별 31–69″) |
| radial p95 | 62″ | **155″** |
| B↔C 같은 프레임 중심 어긋남 | med 101″ (n=9) | |

- 이날 밤 하이브리드 정확도는 **1σ ≈ 1′, p95 ≈ 2.6′** — 어두운 밤 실측
  (1σ 7–17″, §6.5/§6.7)보다 크게 나쁘다. 원인은 밝은 배경의 낮은 SNR:
  솔브 RMSE가 25″대 → 87″로 올라간 것과 정합. 파인더 용도
  (아이피스 시야 0.5–1°)에는 여전히 충분한 수준.
- B(풀프레임 cedar)는 표본 9장이지만 산포·순도 모두 C보다 좋음 —
  "적게 찾되 깨끗하게"의 전형. 단 18% 솔브율로는 단독 운용 불가.
- 웜픽셀 마스크 동작: masked med 0 — 밝은 배경이 웜픽셀을 σ4 아래로
  잠근 것(§6.5 박명 관찰과 동일, 정상 동작).

### 3.4 추가 실험 — B 전처리 변형: RAW 직결 (2026-08-01 추가 측정)

"cedar 풀프레임에 RAW를 바로 넣으면?"에 대한 답. 먼저 전제 정리:
**어느 변형에도 디베이어는 없다** — imx462는 실측 모노(§6.4)이고 솔브
체인은 전 구간 휘도 연산이라, 기존 B도 디베이어 없이 raw 모자이크를
그대로 썼다. 따라서 비교 대상은 전처리 유무다. cedar의 gRPC `Image`는
8-bit 전용이므로 "직결"은 상위 8비트 절단(>>4)으로 정의했다:

- **B1** (기존 B): (raw − 238) × 255/3857 프로덕션 스트레치
- **B2** (RAW 직결): raw >> 4 — 바이어스 차감·스트레치 없음

같은 50장 동일 노출 재실행 결과:

| 지표 | B1 스트레치 | B2 RAW 직결 |
| --- | --- | --- |
| 솔브율 | 18% (9/50) | **18% (9/50)** |
| 검출 수 med (크롭 내) | 5 (1) | 5 (1) — **프레임별 검출 수 차이 med/p10/p90 전부 0** |
| 매치 med / 순도 | 8 / 89% | 8 / 89% |
| RMSE med | 90″ | 92″ |
| 검출 시간 med | 72 ms | 66 ms (경합 잡음 이내) |
| 같은 프레임 솔브 일치 | 공통 8, B1만 1, B2만 1 (한계 프레임의 양자화 요동) | |
| 공통 솔브 중심 어긋남 | med **0.7″** (p90 17″) | |

**판정: cedar 검출은 아핀 밝기 변환에 사실상 불변** — σ 임계가 자체
노이즈 추정 대비 상대값이라, 바이어스 차감/스트레치는 검출·솔브에
아무 이득도 손실도 주지 않는다. 풀프레임 cedar의 병목은 전처리가 아니라
**물리적 SNR**(밝은 배경)이며, 전처리 생략으로 풀프레임 경로의 CPU를
아낄 수 있다는 정도가 실용적 함의다(스트레치 자체는 카메라 프로세스가
크롭 경로용으로 어차피 수행). 스크립트: `bench_b_variants.py` /
`aggregate_b.py`, 결과 `bench_b_variants.jsonl`.

## 4. 판정

1. **ADR m0023(하이브리드 상시화) 재확인**: 목표조건(광해 하늘)에서
   cedar 크롭은 0%, 하이브리드는 88–90%. 이날 밤 기준 두 경로의 역할
   분담이 아니라 **SEP 전담**이었다.
2. **cedar 풀프레임 σ8은 이 밝기에선 대안이 아님** (18%). 어두운 하늘
   한정의 고순도 보조 경로라는 §6.7 판정 유지 — "보류" 결정 변경 근거
   없음.
3. **밝은 하늘에서 정확도 저하(1σ ~1′)는 새 데이터 포인트**: 지금까지의
   7–17″ 실측은 상대적으로 어두운 밤 기준이었다. 노출이 수동 200 ms
   고정이었던 점도 변수 — 자동 노출이 배경 포화(p50 87%)를 피했으면
   SNR·산포가 개선됐을 가능성 있음(다음 밝은 밤에 AE on으로 재측정
   가치).
