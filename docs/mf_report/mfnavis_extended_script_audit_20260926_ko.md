## 실행 검증

- 격리된 `/var/tmp` 데이터 폴더에서 이미지 다운로드 없이 정적 캐시를 생성했다.
  첫 실행은 103.6초에 52.3MiB를 만들었고, 재실행은 14.0초에 완료했다.
  변경 후 재실행에서는 혜성 서버 접속 시도가 없었다. 시험 폴더는 삭제했다.
- 현재 배포 INDI 아카이브에는 `indi_lx200_OnStepX`가 있고, 메타데이터의
  OnStepX 패치 SHA-256이 저장소의 패치 파일과 일치했다.
- 이미지·카탈로그·웹 회귀 테스트 412개 통과, 2개 건너뜀. 추가로 캐시·설치·
  위치 카탈로그 관련 테스트 36개 통과. 셸 문법, Python 컴파일, Ruff,
  `git diff --check` 통과.
- 현 데이터 기준 카탈로그 이미지 조회 대상 18,026건 중 POSS 누락은 없고 SDSS
  누락은 9,397개였다. SDSS 누락이 모두 서베이 영역 밖이라는 뜻은 아니다.

전체 INDI 소스 빌드는 의존 패키지와 실행 서비스를 변경하므로 실행하지 않았다.
인터넷 다운로드도 수행하지 않았으므로 외부 이미지 서버의 응답 품질·속도는
검증 범위 밖이다.
