# MFDS 공개 전환 후 정리 — 2026-09-16

## 작업 전 계획

- 전처리의 빈 Cedar 검출·솔빙 분기를 제거하고 실제 MFDS 우선 검출 결과를 보정 입력에 연결한다. RAW 보정 입력도 실제 검출이 끝난 뒤 구성한다.
- 전처리 후보 부족 또는 프레임 불일치 시 같은 프레임의 RAW 입력을 보존한다. 좌표는 원본 센서 좌표계를 유지한다.
- 이미 검출기에서 적용하는 필터와 중복되는 Cedar 전용 설정, 사용되지 않는 메뉴·계산 보조 코드를 정리한다.
- 운영 MFDS 빌드와 비교 도구 빌드를 구분하고 현재 구조 설명을 갱신한다.
- NixOS, SEP 보조 검출, 병렬 전처리 및 RAW 실패·정렬·보정 시 동기 대기, 비교 도구, 라이선스와 과거 실측 기록은 유지한다.
- 회귀 테스트, 정적 검사와 네이티브 빌드를 검증한다. 새 버전·정식 릴리즈 태그는 만들지 않는다.

## 검증 및 결과

- RAW 검출 후 `SepRun.frame_id`로 프레임을 확인하고 실제 원본 좌표를 보정에 전달한다. 전처리 입력도 같은 프레임만 허용하며 배열을 복사하여 후속 처리와 분리한다.
- 왜곡 보정은 40개, 렌즈 측정은 중앙 센서 크롭 안 8개가 미달하면 기존 RAW 입력을 유지한다. 비정상 좌표·빈 결과·이전 프레임은 보정 입력을 덮어쓰지 않는다. 실제 보정 승인 기준과 저장 방식은 유지한다.
- 빈 Cedar RAW/전처리 단계, 사용되지 않는 전용 솔빙 함수·타임아웃·가짜 병렬 분기를 제거했다. 중앙과 전체 후보가 같으면 전처리 솔빙을 한 번만 시도한다.
- 전처리 진단은 실제 검출기와 후보 수를 기록한다. `sep_*` 경로와 과거 진단 스키마는 비교 자료 호환을 위해 유지한다. 광학 프로필 변경 시 캐시 무효화, RAW 실패·정렬·보정 중 동기 처리 정책은 유지한다.
- `solver_cedar_fullframe`, `solver_cedar_ff_gates` 기본 설정과 중복 `solver_preprocess_async` 기본값을 제거했다. 카메라는 항상 MFDS용 RAW를 게시한다. 필터는 MFDS/SEP 검출 단계에서 적용하며 선택적 전처리 지평선 마스크는 실제 후보에 연결한다.
- 사용처가 없는 `MenuScroller`, `gamma_correct_low/high`, `hash_dict`, `_weighted_radec`를 제거했다. 호환 목적의 광각 API와 비교 도구는 유지한다.
- MFDS `3eb1067`에 `make runtime`을 추가했다. PiFinder 설치 준비는 `--runtime`, 개발/CI는 기본 `--with-tools`를 사용한다. 네이티브 검출 알고리즘·라이선스는 변경하지 않았다.
- 현재 구조 문서의 Cedar gRPC 설명을 MFDS 자식 프로세스·memfd 방식으로 갱신했다. NixOS 코드·워크플로·마이그레이션 기능은 변경하지 않았다.
- 운영에서 참조하지 않는 초기 `~/mf_detect_star` 사본은 로컬 테스트 자료의 `work/mf_post_publication_cleanup_20260916/legacy_mf_detect_star`로 이동하여 비공개 보관했다. 공개 원본은 `~/MFDS`로 유지한다.
