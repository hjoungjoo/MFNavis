# GOTO 이후 펄스 보정 발산과 재획득 수정 (2026-09-18)

## 관측 증거

- 20:42:37 GOTO 근거리 정렬 진입 오차는 11.29분각이었다.
- 물리축 접근 오차가 약 9~10분각에서 정체되어 20:43:30 펄스로 전환했다.
- 이후 남쪽/동쪽 2.5초 펄스가 계속 전송됐지만, 솔빙으로 측정한 오차는
  20:47경 179분각 이상으로 증가했다. INDI 전송 성공은 실제 목표 접근 성공이 아니다.
- 기존 서비스는 이동 또는 펄스가 있으면 정체 타이머를 갱신했다.
  따라서 펄스가 오차를 키워도 무기한 근거리 단계에 머물 수 있었다.
- 승인받아 자동 보정을 중지한 뒤 기본 추적을 유지하고 북쪽/서쪽에 각각
  2초 펄스를 한 번씩 보냈다. 카메라 좌표 변화와 마운트 좌표 변화가 일치하지
  않았지만, 기본 추적 드리프트와 솔빙 산포가 섞여 있어 축 반전 설정을
  임의 변경할 근거로 삼지 않았다.

## 수정

- 근거리 물리축 접근이 수렴하지 않으면 펄스로 무조건 넘기지 않고 `reacquire`를
  요청한다. 같은 목표를 유지하고 새 솔빙에 기반한 sync+GOTO로 복구한다.
- 펄스 보정의 최선 오차보다 `max(2분각, 설정 정확도)` 이상 큰 오차가 서로 다른
  후속 솔빙 3개에서 연속 확인되면 추가 펄스를 중단하고 재획득을 요청한다.
  솔빙 실패, 오래된 영상, 동일 영상 재조회는 발산 증거에 포함하지 않는다.
- 해당 목표에서 신뢰할 수 없었던 미세 보정은 재획득 후 다시 켜지지 않는다.
  GOTO는 최종 정확도까지 sync+GOTO를 사용하며, 추적 중에는 추적 정확도를
  벗어나면 같은 방식으로 복구한다. 새로운 명시적 GOTO는 이 판단을 초기화한다.
- 사용자 정지, 통신/동기화 실패, 주차, 기존 추적 고도 제한은 유지한다.
