# MFNavis 전체 검증 및 기기 적용 — 2026-09-23

## 범위

MFDS 저장소 공개 설정, 소스, 설치된 패키지 및 lock은 변경하지 않았다. MFNavis 제품명·로고·웹·기기 UI·번역·설치/업데이트 변경분을 검증했다. 테스트 설정·데이터·런타임은 별도 임시 디렉터리에 격리했다.

## 발견 및 수정

- 브랜드 일괄 치환으로 테스트 subprocess 안의 `from PiFinder import utils`까지 MFNavis로 바뀐 부분을 원래 호환 패키지 이름으로 복구했다.
- 로그 sink가 문자열 파일 경로를 받으면 `.parent`에서 실패하던 기존 문제를 수정했다. 생성 시 `Path`로 정규화하며 기존 Path 입력도 지원한다.
- 로그 시작 전후 테스트는 현재 로깅 설정의 레벨을 명시하고 동일 초기 큐를 사용하도록 수정했다.
- 좌표 입력 테스트의 폐기된 의존성 주입 인자 사용을 실제 모듈 경계의 monkeypatch로 교체했다. 원래의 좌표·호출 인자 검증은 유지했다.
- UI 전체 커버리지 검사에서 다른 테스트가 만든 가짜 화면 클래스를 제품 화면으로 집계하던 간섭을 수정했다. 실제 `PiFinder.ui` 화면만 집계한다.
- `sys_utils.py` 서식을 정리했다.
- 실제 Flask 경로를 이용한 제품 로고·라이선스 접근·새 백업 다운로드·구형 이름 백업 복원 및 여러 화면 크기의 로고/도움말 회귀 테스트를 추가했다.

첫 전체 실행은 3,260개 통과·13개 실패·6개 건너뜀으로 문제를 발견했다. 테스트 중 `/tmp` 용량이 부족해 문서 빌드 산출물을 `/var/tmp`로 옮겼다. 후속 실행의 격리 데이터 디렉터리 누락도 수정한 뒤 검증을 다시 수행했다. 사용자 데이터와 설정을 이 문제 해결에 사용하지 않았다.
