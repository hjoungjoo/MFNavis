# MFNavis m2.6.12 — 푸시 카메라 확대 및 로고 색상 수정

- 푸시 화면을 열면 카메라 보기를 기본으로 표시한다.
- 카메라 보기에서 `+`/`-`로 1배·2배·4배 확대·축소하며 현재 배율을 표시한다.
- 2배·4배에서는 조준점이 카메라 표시 영역 중앙에 유지된다. 센서 밖은 검게 채우며, 유효한 조준점이 없으면 영상 중앙을 확대한다.
- 정렬 링의 위치·각도 크기를 확대 영상에 맞추고, 방향 안내 계산은 원본 카메라 좌표를 유지한다.
- 부팅 splash와 시작 콘솔에서 RGB 로고의 빨강·파랑 채널이 뒤집히던 오류를 수정한다.
- 사용 안내와 확대·조준점·색상 회귀 테스트를 보강한다.

기존 MFDS 고정 패키지와 사용자 데이터는 변경하지 않는다.
소프트웨어 소스·설치 스크립트 릴리즈이며 OS 이미지는 포함하지 않는다.
실제 LCD 색상과 물리 버튼 동작은 육안 검증하지 않았다.
