# MFNavis m2.6.16 검증 기록

검증일: 2026-10-07. Raspberry Pi 5 / Trixie 64-bit / Python 3.13.

## 변경 범위

MFDS v0.4.3, 소스 커밋 `de25af69d3c4a8450af0b2a7479db6d2e5675b14`의
일반·process-only 판매용 패키지를 새로 고정한다. `/proc` 파일 open / read
사이에 native worker가 종료되는 경쟁 상태를 테스트에서 정상 종료로 처리한다.
검출 알고리즘·C ABI 1·MFDS1 프로토콜과 MFNavis 애플리케이션 동작은 유지한다.

## 패키지 검증

- MFDS 원본의 detector 9개, temporal reduction 35개 창과 image-loading 검사가 통과했다.
- MFDS main의 native·sanitizer·no-libpng CI와 ARM64/x86_64 배포 패키지 CI가 통과했다.
- 일반·판매용 패키지 4개에서 source commit, clean source, version, ABI,
  ELF 아키텍처, manifest·내부 파일 해시 및 checksum sidecar를 확인했다.
- 일반 패키지 양쪽에 수정된 부모 종료 테스트가 포함됨을 확인했다.
- 릴리즈에 업로드한 8개 아카이브·checksum 자료를 다시 내려받아 빌드 파일과 대조했다.
- ARM64 패키지를 MFNavis 설치기로 설치하고 서버의 `MFDS 0.4.3` 응답을 확인했다.

## 소비자 검사

- 설치된 v0.4.3의 프로세스 경계·일반 배포·판매용 설치 검사: **57 통과**.
- 설치된 패키지의 부모 종료 검사: **30회 연속 통과**.
- Ruff lint / format 463개 파일과 MyPy 233개 소스 파일 검사가 통과했다.
- GitHub Nox는 Python 3.11의 lint·format·MyPy·smoke·unit·UI와
  Trixie Python 3.13의 코드·문서·설치 검사를 수행한다.
  정식 게시 전 해당 검사를 통과해야 하며 최종 실행 링크는 릴리즈 본문과
  `release-manifest.json`에 기록한다.
