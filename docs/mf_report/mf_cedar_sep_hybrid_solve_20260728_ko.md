# MF_PiFinder 개발 소식 — cedar + SEP 하이브리드 솔빙, 광해 하늘 실증 (2026-07-28)

> [통합 구현 문서](../history/development/solver.md#mf_sep_fullframe_impl_ko)에 있습니다.
> English version: [mf_cedar_sep_hybrid_solve_20260728_en.md](mf_cedar_sep_hybrid_solve_20260728_en.md)

## 무엇을 하려는 프로젝트인가

PiFinder는 망원경에 붙여 "지금 어디를 보고 있는지"를 플레이트 솔빙으로
알아내는 장치입니다. 그런데 도심의 심한 광해에서는 카메라에 별이 몇 개
안 잡혀서 기본 솔버(cedar-detect)가 자주 실패합니다. 이 포크(MF_PiFinder)는
**"광해로 별이 몇 개만 보이는 하늘에서도 정확하게 솔빙되는 파인더"**를
목표로 개발 중이고, 이번에 그 핵심 기능이 실제 하늘에서 동작하는 것을
확인했습니다.

## 어떻게 적용되어 있나 — cedar + SEP 하이브리드 구조

핵심은 **기존 솔버를 대체하지 않고, 두 검출기의 강점을 조합**한 것입니다.

**1) 기본 경로(cedar)는 그대로 우선 실행됩니다.** 매 프레임마다 기존
PiFinder와 동일하게: 센서 프레임을 크롭·8-bit 변환·512×512 축소 →
cedar-detect 검출 → tetra3 솔브. 별이 충분한 하늘에서는 이 경로가
기존처럼 빠르고 검증된 결과를 냅니다. **기존 동작은 무변경입니다.**

**2) cedar가 실패하면 SEP 경로가 이어받습니다.** 카메라가 매 프레임의
**비크롭 12-bit 원본**을 함께 공유해 두는데, cedar 솔브가 실패한 시도에서
이 원본으로 2차 검출을 돌립니다:

- **왜 원본인가**: 기본 경로의 8-bit 변환은 광해 배경 위 어두운 별을
  2~3계조로 눌러버리고, 크롭은 시야(별 수)를 절반 이하로 줄입니다. SEP
  경로는 12-bit 그대로, 프레임 전체(시야 2.16배)에서 검출합니다.
- **검출 방법**: 2×2 비닝(SNR 2배) → SEP(Source Extractor) 메시 배경
  제거 — 광해 그라디언트·구름 글로우를 국소적으로 빼내서 어두운 별을
  살립니다 → σ4.0 임계 검출.
- **오검출 방어 4중**: 정적 웜픽셀 맵(센서 결함 47위치 자동 생성),
  점광원 형태 게이트(구름 조각처럼 퍼진 검출 제거), 클러스터 게이트
  (구름 가장자리가 만드는 "검출 뭉텅이" 제거 — 실별은 이 배율에서 항상
  고립), 그리고 최종적으로 tetra3의 패턴 매칭이 가짜를 기각합니다
  (야간 내내 오솔브 0).
- **좌표 정합**: SEP 솔브 결과는 회전·스케일 매핑으로 기존 512 기준
  좌표계에 정확히 환산되어(검증: 두 경로 동일 하늘 솔브 시 Roll 편차 0°,
  정렬점 1px 이내) 추적·푸시투·정렬 체인에 **기존과 똑같은 형태로**
  공급됩니다. 하류 코드는 어느 경로가 풀었는지 모릅니다.

**3) 정렬(align)도 같은 하이브리드입니다.** cedar가 되는 하늘에서는 기존
정렬 그대로, 안 되는 하늘에서는 SEP 솔브가 정렬 좌표를 계산해 기존 정렬
체인에 되돌려줍니다 — 광해 하늘에서 정렬이 처음으로 가능해졌습니다.

**4) 헛수고 방지.** 구름 등으로 계속 풀리지 않는 하늘에서는 2차 시도가
지수적으로 쉬어가며(백오프), 별이 다시 보이는 순간(검출 수 급증) 즉시
재가동합니다 — 구름 틈 구제가 지연되지 않습니다.

**5) 자동 노출과의 결합.** 별 수 기반 자동 노출이 "실제로 솔브된 노출"에
앵커를 걸어, 구름이 지나가는 하늘에서도 노출이 출렁이지 않고 스위트스팟에
고정됩니다.

## 이번에 확인된 것 (서울 도심, 박명~야간 실측)

**별이 몇 개 안 보이는 하늘에서 솔빙이 실제로 됩니다.**

- 이 하늘에서 cedar는 별을 평균 1개밖에 못 찾아 직접 솔브 0이었지만,
  SEP 경로가 15~20개를 찾아 **솔빙 전체를 담당**했습니다. 하늘이 좋았던
  구간에서는 5분 솔브율 88~98%.
- **정확도 실측**: 연속 솔브 간 흔들림이 RA 11″/Dec 16″(1σ) — 카메라
  픽셀의 1/3 수준으로, 파인더 용도에 충분한 정밀도입니다.
- 정렬 하이브리드도 간이 테스트로 정상 동작 확인.

## 이번에 고친 것들

- **웜픽셀 제거**: 야간 검출의 절반 이상이 센서의 정적 웜픽셀이었음을
  발견하고, 자동 생성되는 배드픽셀 맵으로 걸러냅니다.
- **구름 오검출 제거**: 구름 가장자리를 별로 오인하는 문제를 실별/비별의
  형태·분포 차이(실별은 항상 고립·점광원)로 걸러냅니다. 검출 순도
  46% → 91%.
- **반응 속도 4.5배**: 솔브 주기 1.35초 → 0.3초 (파이프라인 고정비 제거).
- **모노 센서 정리**: imx462 모듈이 드라이버 라벨과 달리 실측 모노임을
  확인 — RAW의 "컬러 노이즈"는 디베이어 인공물이었고, 프리뷰/다운로드가
  풀해상도 그레이스케일로 정리됐습니다(무손실 16-bit TIFF 다운로드 추가).
- **웹 LiveCam 개선**: 검출 결과를 프리뷰 위에 표시하는 SEP 오버레이 —
  **초록 = 솔버가 실제 별로 확정한 것**(오인 없음 보장), 주황 = 미확정
  후보. 구름 낀 하늘인지 별이 잡히는 하늘인지 한눈에 구분됩니다.
