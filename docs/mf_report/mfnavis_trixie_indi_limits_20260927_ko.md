# 2026-09-27 INDI Settings 제한값 조회·변경

INDI 페이지의 Settings에 천정 고도(60~90°), 지평선 고도(−30~30°),
메리디안 East/West(각각 −180~180분)의 현재값과 편집란을 추가했다.
한국어 라벨과 단위, 축 제한과 별개라는 설명을 제공한다.
현재값은 기존 5초 INDI 갱신 경로를 사용하며 편집 중인 입력을 덮어쓰지 않는다.
연결 Off 또는 누락된 값은 빈칸과 `-`로 표시하고 적용을 비활성화한다.
적용은 로그인과 활성 OnStepX 프로필을 요구한다.

## 쓰기 및 검증

`/indi/limits`는 네 값을 모두 유한한 정수와 드라이버 범위로 검사한다.
INDI 서버로 고도 두 값 및 메리디안 두 값을 각각 **완전한 number vector**로
전송한다. 포트를 직접 열거나 마운트 연결·좌표 정렬·GoTo·추적 명령을 보내지 않는다.
고도 변경은 즉시 반환된 write echo만으로 성공을 판정하지 않고,
전송 후 2초 이후에 도착하는 주기적인 드라이버 재조회 응답과 일치해야 한다.
드라이버 Alert와 ERROR, 연결 끊김, 타임아웃은 실패로 표시한다.
일부 벡터만 적용될 수 있으므로 이미 확인한 항목과 재조회 필요를 알리며,
실패 시 임의 롤백으로 다른 클라이언트 설정을 덮어쓰지 않는다.

## 메리디안 조회의 한계

현재 설치된 INDI 드라이버는 `Minutes Past Meridian`을 모든 모드에서
게시하지만, 컨트롤러 `:GXE9#`/`:GXEA#` 조회는 **GEM 모드에서만** 수행한다.
따라서 경위대에서 표시된 20분/−20분은 INDI 벡터값이며 컨트롤러의
실제 저장값이라고 단정할 수 없다. 경위대에서 이 제한은 메리디안 플립에
사용되지 않는다. 화면에 이 점을 명시했고, 메리디안 쓰기는 fresh Ok 응답과
요청값 일치를 확인한다. 해당 응답을 컨트롤러 독립 재조회로 설명하지 않는다.
이 작업에서 INDI 드라이버 바이너리는 변경하지 않았다.
